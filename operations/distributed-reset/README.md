# 분산 수동 초기화 런북

이 디렉토리는 분산 라즈베리 운영에서 데이터 수집 오염/누락이 발생할 때,
스크립트 없이 수동으로 초기화하는 절차만 정리한 운영 런북이다.

## 핵심 답변

- 가능: Elasticsearch, Neo4j에 직접 접속해서 삭제/초기화 가능
- 가능: PostgreSQL 테이블 단위 TRUNCATE 가능
- 가능: Edge 로그 파일 truncate 가능
- 주의: DB 엔진 내부 데이터 파일을 직접 삭제/덮어쓰기하는 방식은 비권장

DB 파일을 직접 만지면 인덱스/트랜잭션 상태 불일치로 복구가 어려워질 수 있다.
항상 엔진이 제공하는 API/쿼리/볼륨 관리 방식으로 초기화한다.

## 운영 원칙

1. 수집 정지(Detection 중지) 후 초기화
2. 저장소별 논리 삭제(API/쿼리) 우선
3. 필요 시에만 Filebeat offset 리셋
4. 최후 수단으로만 볼륨 삭제 재생성
