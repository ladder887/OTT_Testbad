# OTT 불법 사용자 탐지 연구/운영 문서 인덱스

> 갱신일: 2026-04-19  
> 현재 실행 기준은 `10`, `11`, `12`, `13`, `15` 문서이며, 공격 시나리오 기준 문서는 `07`이다.
> 연구 범위는 OTT 환경에서의 불법 사용자/불법 행위 탐지 전반이며, 불법 시청은 여러 불법 행위 유형 중 하나로 포함한다.
> `CDN Leeching`은 공격 시나리오의 한 축(A계열)으로 다룬다.

## 2. 권장 읽기 순서

### 2.1 실제 시스템을 실행/운영할 때

1. `10` (로컬 검증)
2. `15` (초기화/라벨 수집 통합 절차)
3. `11` (분산 배포)
4. `12`, `13` (장비별 실행)
5. 필요 시 `09` (구조 요약)

### 2.2 연구 설계/논문 정리 시

1. `01`~`08` 순서대로 검토
2. 공격 시나리오는 `07`을 기준으로 확인
3. 실제 구현 차이는 `09`, `10`, `11`, `15`으로 교차 확인

## 3. 핵심 연구 메시지

> 본 연구는 OTT 환경에서의 불법 사용자/불법 행위 탐지를 대상으로  
> 규칙 기반, 전통 ML, GNN의 성능과 적용 한계를 비교한다.  
> 단순 공격은 규칙 기반으로 충분할 수 있으나, 관계/연쇄 기반 회피 공격에서는  
> 그래프 기반 접근의 이점이 커진다는 점을 실험적으로 검증한다.
