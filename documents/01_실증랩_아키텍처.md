# 01. 실증랩 아키텍처 (192.168.0.x/24 단일 서브넷)

> **운영 정정 (2026-04-04):** Edge 4개를 1대 호스트의 포트 분리로 운용하던 임시 구조는 폐기했다.
> 현재 운영 기준은 Edge Pi 4대 물리 분리이며, 실제 실행 절차는 `11_라즈베리_및_서버_분산배포_매뉴얼.md`를 우선한다.
> 라이브 확장 기준(`10`, `11`)에 따라 서버#1에 `live-encoder`를 추가하고, 플랫폼에 라이브/콘텐츠 구분 및 영상관리 페이지를 적용한다.

---

## 1. 설계 원칙

- 단일 서브넷 **192.168.0.0/24** 사용 (공유기 기본 설정 그대로)
- IP 끝자리 범위로 지역, 서버 역할을 논리적으로 구분
- 클라이언트: 1~99번 대역, 서버: 100번 이상 대역
- CDN Edge는 edge-kr/jp/sg/us를 서로 다른 Edge Pi로 물리 분리
- 생성되는 CDN 로그 데이터는 물리 분리 환경과 **완전히 동일**
- 서버#1은 VOD + LIVE 동시 제공 (origin-nginx + live-encoder)
- 플랫폼 UI는 콘텐츠(VOD)/라이브(LIVE) 카테고리를 분리해 운영

## 4. IP → 지역/ASN 매핑 로직

IP 끝자리의 **십의 자리**로 지역을 판별:
- 1x → KR, 2x → JP, 3x → SG, 4x → US

```python
# shared/region_map.py

def get_region(client_ip):
    """IP 끝자리 십의 자리로 지역 판별"""
    parts = client_ip.split(".")
    if parts[0] != "192" or parts[1] != "168" or parts[2] != "0":
        return "UNKNOWN"
    
    last_octet = int(parts[3])
    if 11 <= last_octet <= 19:
        return "KR"
    elif 21 <= last_octet <= 29:
        return "JP"
    elif 31 <= last_octet <= 39:
        return "SG"
    elif 41 <= last_octet <= 49:
        return "US"
    return "UNKNOWN"


# Edge 매핑 (지역 → Primary Edge URL)
EDGE_MAP = {
    "KR": {
    "primary": "http://192.168.0.111",
    "backup":  "http://192.168.0.112",
        "id": "edge-kr"
    },
    "JP": {
    "primary": "http://192.168.0.112",
    "backup":  "http://192.168.0.113",
        "id": "edge-jp"
    },
    "SG": {
    "primary": "http://192.168.0.113",
    "backup":  "http://192.168.0.114",
        "id": "edge-sg"
    },
    "US": {
    "primary": "http://192.168.0.114",
    "backup":  "http://192.168.0.111",
        "id": "edge-us"
    },
}

def get_primary_edge(client_ip):
    region = get_region(client_ip)
    return EDGE_MAP.get(region, EDGE_MAP["KR"])


# ASN 시뮬레이션
# 기본: 정상 사용자 → residential ASN
ASN_BY_REGION = {
    "KR": {"asn": "AS4766",  "asn_name": "Korea Telecom",  "asn_type": "residential"},
    "JP": {"asn": "AS2516",  "asn_name": "KDDI",           "asn_type": "residential"},
    "SG": {"asn": "AS9506",  "asn_name": "SingTel",        "asn_type": "residential"},
    "US": {"asn": "AS7018",  "asn_name": "AT&T",           "asn_type": "residential"},
}

# 오버라이드: 공격자 IP → datacenter ASN (시나리오 A4, A6용)
ASN_OVERRIDE = {
    "192.168.0.13": {"asn": "AS14061", "asn_name": "DigitalOcean",  "asn_type": "datacenter"},
    "192.168.0.22": {"asn": "AS16509", "asn_name": "Amazon AWS",    "asn_type": "datacenter"},
    "192.168.0.32": {"asn": "AS15169", "asn_name": "Google Cloud",  "asn_type": "datacenter"},
    "192.168.0.43": {"asn": "AS13335", "asn_name": "Cloudflare",    "asn_type": "datacenter"},
}

def get_asn_info(client_ip):
    # 오버라이드 먼저 (공격 시나리오에서 datacenter IP 시뮬레이션)
    if client_ip in ASN_OVERRIDE:
        return ASN_OVERRIDE[client_ip]
    # 기본: 지역별 residential ASN
    region = get_region(client_ip)
    return ASN_BY_REGION.get(region, {"asn": "UNKNOWN", "asn_name": "Unknown", "asn_type": "unknown"})
```

## 7. 서버#1 구성 (192.168.0.100: API/Auth + Origin)

```yaml
# docker-compose.server1.yml
version: '3.8'

services:
  api-server:

    container_name: api-server

      - "3000:3000"

      - JWT_SECRET=your_jwt_secret_key_here

      - redis

  postgres:

      - POSTGRES_DB=ottdb

      - ./data/postgres:/var/lib/postgresql/data

    image: nginx:1.24-alpine
    container_name: origin
    ports:
      - "8080:80"
    volumes:
      - ./nginx/origin.conf:/etc/nginx/nginx.conf:ro
      - ./content:/var/www/content:ro
    restart: unless-stopped
```

### 8.4 멀티 사용자 실행

```python
# run_client.py
import asyncio, yaml

async def run_virtual_user(config, user_idx):
    cred = config["credentials"][user_idx]
    scenario = config["behavior"]["scenario"]
    role = config["behavior"]["role"]
    
    if role == "normal":
        from scenarios import normal
        await normal.run(config["api_server"], cred, scenario)
    else:
        from scenarios import attacker
        await attacker.run(config["api_server"], cred, scenario)

async def main():
    with open("config.yml") as f:
        config = yaml.safe_load(f)
    
    tasks = []
    for i in range(config["behavior"]["virtual_users"]):
        tasks.append(run_virtual_user(config, i))
    await asyncio.gather(*tasks)

if __name__ == "__main__":
    asyncio.run(main())
```

## 11. 논문 기술 표현

> "본 연구의 실증 환경은 Raspberry Pi 기반 물리 클라이언트 10대와
> 서버 3대로 구성하였다. 모든 장비는 192.168.0.0/24 단일 네트워크에
> 연결하였으며, 4개 지역(KR, JP, SG, US)은 IP 주소 범위 기반의
> 논리적 매핑으로 구분하였다. CDN Edge 서버 4대는 Docker 컨테이너로
> 구동하여 각각 독립된 캐시, 토큰 검증, 로그 수집 기능을 갖추었다.
> 각 클라이언트는 비동기 방식으로 2~3명의 가상 사용자를 동시
> 시뮬레이션하여, 총 20~30명 규모의 OTT 시청 환경을 재현하였다."
