## 2. HLS 패키징

### 2.1 ffmpeg 명령어

```bash
#!/bin/bash
# package_hls.sh — Origin 서버에서 실행

INPUT="source_movie_001.mp4"
OUTPUT_DIR="/var/www/content/movie_001"
mkdir -p $OUTPUT_DIR/{1080p,720p}

# 1080p
ffmpeg -i $INPUT \
  -vf scale=1920:1080 -c:v libx264 -b:v 5000k -c:a aac -b:a 128k \
  -hls_time 6 -hls_list_size 0 \
  -hls_segment_filename "${OUTPUT_DIR}/1080p/seg_%04d.ts" \
  "${OUTPUT_DIR}/1080p/playlist.m3u8"

# 720p
ffmpeg -i $INPUT \
  -vf scale=1280:720 -c:v libx264 -b:v 2500k -c:a aac -b:a 96k \
  -hls_time 6 -hls_list_size 0 \
  -hls_segment_filename "${OUTPUT_DIR}/720p/seg_%04d.ts" \
  "${OUTPUT_DIR}/720p/playlist.m3u8"

```

### 2.2 Master Playlist

```m3u8
# /content/movie_001/master.m3u8
#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=5128000,RESOLUTION=1920x1080,NAME="1080p"
1080p/playlist.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=2596000,RESOLUTION=1280x720,NAME="720p"
720p/playlist.m3u8
```

### 2.3 세그먼트 규격

| 항목 | 값 |
|------|-----|
| 세그먼트 길이 | 6초 |
| 컨테이너 | MPEG-TS (.ts) |
| 비디오 코덱 | H.264 |
| 오디오 코덱 | AAC |
| 세그먼트 네이밍 | seg_0001.ts, seg_0002.ts, ... |

## 3. 라이브 스트리밍 시뮬레이션

### 3.1 서버#1 live-encoder 컨테이너 기반 생성

운영 기준은 `deploy/server1/docker-compose.yml`의 `live-encoder` 서비스다.

- 입력 소스: `origin/source/sample.mp4`
- 출력 경로: `origin/hls/live_001/`
- 출력 해상도: `1080p`, `720p`
- `master.m3u8`는 컨테이너 시작 시 생성

### 3.2 수동 ffmpeg 시뮬레이션 예시

```bash
# live_simulator.sh — 무한 루프로 라이브 세그먼트 생성
#!/bin/bash
SEG_NUM=1
while true; do
    ffmpeg -re -i loop_source.mp4 \
      -vf scale=1920:1080 -c:v libx264 -b:v 5000k \
      -c:a aac -b:a 128k \
      -f hls -hls_time 6 -hls_list_size 10 \
      -hls_flags delete_segments+append_list \
      -hls_segment_filename "/var/www/content/live_001/1080p/seg_%05d.ts" \
      "/var/www/content/live_001/1080p/playlist.m3u8"
done
```

라이브 매니페스트는 최근 10개 세그먼트만 유지 (슬라이딩 윈도우).
이 특성이 A6(라이브 이벤트 동시 탈취) 시나리오에서 중요함.

## 4. Origin 서버 Nginx 설정

```nginx
# origin.conf
server {
    listen 80;
    server_name origin.cdn.local;

    root /var/www;

    location /hls/ {
        # Origin은 토큰 검증 안 함 (Edge만 검증)
        # 단, Edge에서만 접근 가능하도록 IP 화이트리스트
      allow 192.168.0.111;  # edge-kr
      allow 192.168.0.112;  # edge-jp
      allow 192.168.0.113;  # edge-sg
      allow 192.168.0.114;  # edge-us
        deny all;

        add_header Access-Control-Allow-Origin *;
        add_header Cache-Control "public, max-age=3600";
    }
}
```
